# Progress

iOS-first fitness tracking app. Train. Track. Progress.

## Stack

Expo, React Native, TypeScript, Expo Router, Supabase (not wired yet).

## Setup

1. Copy `.env.example` to `.env` (values are unused until the Supabase milestone).
2. Install dependencies: `npm install`
3. Start: `npm start`

## Scripts

- `npm start` — Expo dev server
- `npm run typecheck` — TypeScript
- `npm run doctor` — Expo diagnostics
